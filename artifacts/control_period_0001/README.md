# Control-period feasibility (route b)

Everything about the archived task is kept (object, friction, gains, reset, success audit, planner recipe) except the control period `control_seconds` of the environment, which the paper reference records as 10 Hz (`configs/paper_reference.json`, `rotation/control_hz`). A longer period is a disclosed deviation whose purpose is to make each control's consequences less chaotic (route (a) found that at 0.1 s a perturbation of L2 0.0003 on one control breaks the open-loop replay of a demonstration and that the per-step slack of 0.005–0.01 lies below any learnable law's precision).

`probe.py <period> <seed_from> <seed_to>` builds the environment with the given period (physics timestep unchanged at 2 ms, so 50 / 100 / 150 / 250 substeps for 0.1 / 0.2 / 0.3 / 0.5 s; the horizon kept at the archived 100 control decisions), runs cold-reset MPC attempts with the archived corrected recipe (planner step = period, horizon = 5 periods, 6 knots, CEM 350/10/3, diagnostic prior, .98 bound) under the strict force-qualified success audit, and for every success measures the open-loop tolerance: control j perturbed by L2 r in 3 directions, the rest replayed, the last control held up to 20 more times. Results: `probe_P<ms>ms_seeds*.json`, episodes in `episodes/`. Outcome (2026-10-08): no period widens the tolerance; see findings.md. The probe also carries `--shape` and `--diameter` options used by the object-shape diagnostic (`object_shape_0001`).
