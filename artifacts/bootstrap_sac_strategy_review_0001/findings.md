# Next bootstrap-SAC route after the measured support screen

**Use one bounded prefix-7 SAC learning test next.** Physically replay seven actual controls of the successful common 60D BC trajectory after each cold reset, then let the unchanged-interface stochastic actor control the suffix. Keep prefix 8 as a separate assisted retention check. This is a local reset-distribution curriculum for the unpublished companion prerequisite, not the main method or a successful cold-start SAC policy. Do not run another sparse BC/head-fitting round as the primary next step.

The completed support probes materially change the available evidence. The original bootstrap0005 initialization has latent std 0.05 and BC count 12,000, with zero critic pretraining and zero SAC updates. From the exact state after eight actual controls, all five prescribed stochastic suffixes completed on their first action. The fixed descending rollback screen then tested prefix 7: two of five completed in two suffix actions; two dropped and one violated palm support. Its deterministic policy suffix reproduced the full original nine-control trace bit-for-bit. The screen stopped immediately at its prespecified below-four-of-five gate; prefixes 6–1 were not tested. All prefix states, transition/integration fields and 2 ms physics matched the source, and suffix action/log-probability/RNG reconstruction passed exactly. These are assisted positive and negative learning outcomes, not a measured general reliability rate. Reusing five seeds is useful for phase comparison but makes fresh held-out evaluation seeds necessary.

## Why this route has stronger support

The existing 60D mean already completes the nominal cold-reset turn, while its sampled cold trajectories fail. Neither a clock nor near-exact finite-dataset interpolation fixed closed-loop sensitivity: the final 86-pair clock head achieved maximum recorded-state action error 4.77e-7 and still dropped at control 19. More precision could change a sensitive nominal rollout, but it cannot by itself establish robustness to the deliberately retained std 0.05 exploration. Further head solves also increase conditioning and local-gain concerns. Their fitting error is not a control-stability metric.

Directly measured MPC feedback is stronger evidence than another fit. Corrected MPC recovered all five actual noisy nine-control states with 21 total additional commands, and recovered the later clock actor state with five commands. The counterfactual old teacher continuation failed where actual MPC corrections succeeded. However, supervised imitation of the growing sparse correction set still failed. This supports using actual state-dependent feedback when needed, not a claim that a particular number of more demonstration rows will solve it.

The prefix-7 screen supplies real stochastic success and failure without an MPC query or a new observation interface. It therefore tests whether ordinary online SAC can exploit existing action support before paying for large-scale teacher acquisition. It does not prove that the support generalizes to new seeds, that critic updates are well conditioned, that the actor will improve, or that suffix learning transfers to startup. The finite screen also cannot establish that an untested earlier phase has no successes.

The critic experiments strengthen the need to measure learning rather than infer it from loss. Frozen-policy Monte Carlo centering improved parts of value fitting, but the paired action-direction test favored the critic's proposed direction in realized soft return for only two of five cases; all ten tested trajectories failed. Teacher-continuation Monte Carlo returns estimate a different continuation policy's value and must not be presented as the actor's Q value. Do not transfer these custom diagnostic critic fits or relabel their updates as SAC.

## Source and provenance boundary

The archived companion source specifies simulation SAC on a 40 mm hexagonal object without domain randomization, followed by policy trajectories and 90%-variance PCA. It does not publish the prerequisite's observation, reset distribution, reward shaping, teacher assistance, optimizer or training budget. Thus a disclosed local prefix curriculum or MPC-assisted simulation bootstrap is a possible independent implementation of the missing prerequisite; neither is source-verified reproduction of its unknown recipe.

The route is noncircular only if lineage remains explicit: an existing **diagnostic** MPC-derived prior may assist simulation learning; genuinely executed SAC updates train a policy; a frozen checkpoint then must independently produce five successful **cold-reset policy-only** trajectories; only that measured collection may supply the eligible SAC-source PCA. Diagnostic prior data, prefix-assisted episodes, MPC corrections and BC-origin completions cannot be silently promoted. Main 60D/16D interfaces, its twenty demonstrations and all main-stage gates remain unchanged. The current collector's positive-online-update gate is necessary but is not itself evidence of success or robust learning.

## Smallest controlled learning experiment

The selected prototype should fix prefix 7 for one budget, preserve the initial0005 actor/std/physics, and start with its fresh critics/targets/alpha rather than the later failed bootstrap0005 critics or the custom Monte Carlo fits. No new BC, head refinement, noise reduction, observation augmentation or dynamics randomization is needed. Use only actually executed suffix transitions as the online learner's replay; preserve every physical prefix separately with explicit provenance and cost. No fabricated next action or expert label is required.

A concrete comparable budget is 2,000 actual suffix interactions, batch 256, UTD 1, learning starts 256, actor/critic LR 3e-4, alpha LR 1e-4, initial alpha 0.05, discount .995, Polyak .01 and the existing 5,000-update actor-LR warmup. That warmup ramps a positive learning rate; it is not an actor freeze. This yields at most 1,745 genuine SAC updates. Freeze initial/500/1000/1500/2000 snapshots and stop at the budget or a fault, without automatic extensions. These settings are a proposed local comparison protocol, not companion-paper settings.

Evaluate a fixed new held-out seed set before and after learning at prefix 7, plus a separate prefix-8 retention check and cold-reset policy-only evaluation. Preserve actual force-qualified progress, success/failure flags, prefix versus suffix returns, std/entropy, and all actions/states. Compare frozen critics at the actual sampled state/action against fully observed discounted soft suffix returns under that frozen actor and alpha, stratified by positive and failed outcomes. Exclude the first action's entropy in the Q-like target, retain entropy of later actions, and label unmeasured time-limit tails. Track critic gradients/targets as diagnostics rather than treating their signs or low losses as evidence of better actions.

Only subsequent new held-out learning evidence can justify an earlier curriculum phase. Keep successful assisted suffix counts separate from cold full-policy completions; never reset the angle or success threshold at handoff. A positive assisted SAC count can support continued bootstrap development but cannot supply an extraction trajectory. No training was run in this strategy review.

## Cost and fallback

The rollback audit executed 65 controls with full 2 ms force instrumentation in 1.94 seconds of its measured loop; bootstrap0005 previously executed 2,000 learning interactions in about 50 seconds without these full per-step audits. Prefix-7 replay adds seven real controls per suffix episode. A 2,000-suffix budget therefore has an explicit maximum of 16,000 total controls if every suffix terminates after one action. These are rough machine-specific sizing observations, not a benchmark promise; a separately reported 15-minute wall cap is a reasonable bound, with prefix replay, learning and audits timed separately.

In contrast, the measured 21-query five-branch MPC recovery cost 104.66 seconds of planning, and the five-query clock recovery cost 21.60 seconds: about 4.3–5.0 seconds per correction on the current native eight-worker 350×3 recipe. One hundred queries therefore cost roughly 7–9 minutes, 256 about 18–22 minutes and 1,000 about 72–83 minutes, before collection/audit overhead. Querying every control is substantially more expensive than the demonstrated prefix replay.

If the bounded suffix test fails to turn positive/negative experience into useful held-out behavior, an explicit online MPC scaffold is the next substantive fallback, not an arbitrary precision/BC sweep. Freeze a query budget and one switch rule, collect actual policy-visited states, and store only the action physically executed with its true next state in SAC replay. Keep an unexecuted MPC proposal as a separately labeled query, never pair it with a next state produced by another action. The main 40-control scheduling chunk lasts four seconds and exceeds the observed early failure horizons, so a local bootstrap scaffold would need an explicitly shorter decision schedule rather than an implicit claim to use the main recipe. Its exact intervention trigger remains untested and should be selected once, not tuned post hoc on failed branches.

This recommendation narrows the next uncertainty to whether SAC can learn from already demonstrated stochastic action support. It does not resolve cold-start robustness, sustained rotation, the five-trajectory collection gate, or the main deployment goal.
