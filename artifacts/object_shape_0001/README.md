# Object-shape diagnostic (route b, mechanism test)

`control_period_0001/divergence.py` showed that a demonstration's open-loop sensitivity is a bifurcation at discrete contact events (a hexagonal-prism edge rolling over a fingertip) with contracting dynamics in between, which a longer control period cannot remove. The archived environment supports `object_shape: circular` (`EnvConfig`, diameter = cylinder diameter); this diagnostic runs `control_period_0001/probe.py --shape circular` at the archived 0.1 s period (diameter 0.04 m, and 0.046 m to match the hexagon's corner radius since the archived initial grasp was recorded on the hexagon) and measures the open-loop tolerance of cold-reset MPC successes. A round object is a further deviation from the archived task and from the paper's object; it is run here only to tell whether the geometry is the lever, and nothing here is primitive-eligible.
