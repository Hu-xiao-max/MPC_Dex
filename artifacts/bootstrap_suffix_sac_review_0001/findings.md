# Independent source review: bounded prefix-7 suffix SAC prototype

No remaining blocking issue found in the reviewed `prepare.py` and `run.py` versions recorded in `reviewed_source.json`. Both parse successfully. This is a read-only source review, not an executed training/checkpoint test: no runner import, physics, learning, or source edits were performed. The source snapshots beside this report identify the exact reviewed implementation; subsequent changes need a delta review.

Two concrete findings were reported and fixed by the author before this snapshot:

1. Warmup and online assisted/cold episode and force-success counters are now separate. Frozen BC-origin warmup successes therefore do not inflate online learned-success counts.
2. Required archived modules must exist before imports, and loaded module paths must resolve under the artifact's `source/`. A missing snapshot cannot silently fall back to live workspace numerical modules.

The reviewed behavior is consistent with the intended bounded experiment:

- **Reward and entropy units:** replay stores actual raw rewards and episode returns. Sampling returns copies; only the copied update batch divides rewards by 200. Initial online alpha `.05/200` and SoftSARSA alpha `.02/200` preserve their respective raw-unit entropy weights. Calibration now provides both empirical alpha conventions separately. Scaling rewards/temperature and changing the curriculum together is not a pure curriculum comparison or a guarantee of bit-exact Adam/SAC invariance.
- **Fixed budget and counters:** collection completes 256 frozen-policy suffix episodes, then performs 500 actual critic-pretraining updates. An ineligible SoftSARSA batch raises instead of counting a skipped call. The actor and alpha remain unchanged through pretraining, verified against source hashes/empty optimizers. Online collection performs exactly one genuine `SACAgent.update` per executed policy action; final assertions require BC12,000, pretrain500, and online2,000. The initial copied checkpoint is not counted as newly learned success.
- **Actual transitions only:** each episode physically executes the recorded prefix from reset and checks all prefix transition/integration fields plus every prefix physics sample. Prefix construction never inserts replay rows. Suffix actions are sampled from the actual visited observation using CUDA float32 `(1,60)` and direct returned log probabilities. `ReplayBuffer.add_transition` links only subsequent executed actions within the same episode. Terminal tails have invalid next actions; truncated tails without a recorded successor are excluded from SoftSARSA. Online SAC keeps time limits nonterminal. Empirical return calibration excludes incomplete/truncated tails and current-action entropy.
- **Density precision:** inherited SoftSARSA evaluates the density of recorded next actions using the existing actor's inverse-tanh/clamp `log_prob` method. Empirical return diagnostics use the direct sampler density. This preserves the existing implementation but should not be described as bit-exact raw-latent density reconstruction; no core change is needed for this local experiment.
- **Evaluation isolation:** evaluation uses separate environments, does not sample replay, restores Torch CPU/all-CUDA, NumPy, and Python RNG states in `finally`, and checks actor/critic/target tensors and counters. Prefix-7 evaluations and the selected baseline/final prefix-8 retention probes have separate fixed seeds. Cold evaluations are recorded separately. Replay's independent sampler is untouched by evaluation.
- **Strict outcomes:** force-qualified progress, loaded fingers, no palm/external support, independent drop, and no equality constraint are checked before a force-success count. Environment success remains separately recorded. Raw environment rewards are preserved even if independent qualification rejects an environment-success endpoint; no replacement success reward or fabricated continuation is created. Assisted results and cold-policy results remain explicitly distinct; no primitive trajectories are exported.
- **Checkpoint boundary:** saved generations follow the actual physical transition and completed optimizer update. They include learner/optimizers, raw replay and pending slot, global RNG, complete MuJoCo data, environment observation/scalars/RNG, current episode trace, and observer state. A pending generation is renamed only after its file manifest is assembled. A budget-ending live suffix remains unfinished and nonterminal. There is explicitly **no automatic resume implementation**, so these evidence snapshots must not be advertised as resumable training.

The review approves these code semantics for the separately authorized fixed experiment. It establishes no outcome, robustness rate, published-method fidelity, or cold-start SAC success. Future primitive use requires a new frozen cold-policy collection under the appropriate provenance gates.
