# Bootstrap variant template; stamps frozen one-factor stages from SAC0004

After SAC0003 and SAC0004 (fixed prefix 6, 8 demonstration rows mixed 30/70, no frozen success, prefix-7 retention lost by online 500 even with correct demonstration values), this template expresses the candidate remedies as protocol flags on one runner derived from the SAC0004 runner, so that each variant changes one or two named factors from the same SAC0001 checkpoint.

Protocol-controlled factors: `prefix_set` (collection prefix sampled per episode with its own RNG; every prefix control still physically replayed and verified), `demonstration_include_mpc` and `demonstration_recorded_rows` (demonstration composition), `offline_fraction` (mixing share), `actor_bc_lambda` (supervised MSE toward demonstration actions inside the single SAC actor step), `actor_on_demonstration_states` (whether SAC actor/temperature losses include demonstration rows), and `eval_prefixes` (each checkpoint evaluates every listed prefix plus cold reset). Critic pretraining keeps the entropy-free demonstration target. `runner_update` replicates `SACAgent.update` call-for-call and is unit-tested bit-identical when both additions are off.

`prepare.py --list` shows the variants and hypotheses; `prepare.py --variant NAME` stamps `artifacts/bootstrap_variant_<index>_<name>/` with hash-bound inputs from SAC0004, a copy of this runner and test file, its protocol and execution manifest. Variants are never overwritten. Execution is separate (`run.py --execute`). All assisted and demonstration-mixed data remain ineligible for primitive export.
