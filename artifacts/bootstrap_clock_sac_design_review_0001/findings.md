# Conditional 61D clock bootstrap integration

**Recommendation:** if a clock actor is selected later, add one explicit rotation-only bootstrap observation adapter and one shared interface validator. Keep the physical environment, SAC equations, force criteria and main 60D rotation policy unchanged. Several current 60D gates must change together; accepting every 61D checkpoint would confuse elapsed time with reorientation's goal input. This review implemented nothing and ran no training, physics or tests. It does not assess the ongoing BC experiment or establish a successful clock SAC policy.

The archived companion audit finds its bootstrap observation layout and normalization **unpublished**. Its [simulation-SAC passage](https://arxiv.org/html/2609.14868v1#S3.SS2.SSS1.p3.1) specifies the 40 mm object, no domain randomization and extraction of finger trajectories; it does not impose 60 inputs. The explicit 60/16 network table belongs to the [main real-world learner](https://real-world-rl-with-mpc.github.io/), Implementation Details. Thus an elapsed clock is a disclosed local prerequisite choice, not an author-specified feature or a contradiction of a published companion dimension. This is absence of a constraint in the inspected sources, not proof of the authors' implementation. Exact cached sources and the earlier audit are copied under `reviewed/`.

## Exact clock semantics and source import

Use `float32(data.time - episode_time_origin)` at each real decision and returned next observation. Capture the float64 origin immediately after the real reset. The current `env.py:238` resets simulator time to zero and performs no integration prelude, but explicitly saving origin avoids silently relying on that implementation detail. Clock zero occurs only at an actual reset. It does not restart at an MPC/actor handoff, full turn, checkpoint, evaluator call or resume; each parallel environment owns its own origin. Keep terminal and truncated next observations at their actual final elapsed time, and reset only the subsequent episode's observation. Do not substitute global interaction count, wall time, nominal rounded step timestamps, modulo phase or horizon-normalized time for the selected actor's seconds input.

A small `AllegroRotationEnv` subclass can append after `super().reset/step`, with a61D observation space, without overriding the underlying60D observation computation or physics. This also retains the auditor's direct `finger_contacts` hook. A generic forwarding wrapper needs more state/hook delegation and is not the smallest fit here. Recomputing the entire saved observation on resume can destroy its finite-difference velocity history; preserve the saved vector and check the added clock against restored physical time.

Keep the base `environment_contract` (`contracts.py:21`) as the physical/base-observation identity. A separate policy observation contract must specify kind, rotation task, base60, total61, time index60, float32 seconds, actual reset origin, no normalization, absolute actions, and adapter version/source hash. Reorientation's61st entry is a goal and must remain a different semantic interface.

Existing frozen diagnostic actors use `diagnostic_bootstrap_elapsed_time_absolute_joint_target` with a descriptor copied here; it lacks an implementation version/hash and contains diagnostic eligibility flags. Do not rewrite those immutable sidecars or treat dimensional agreement as equivalence. If a new canonical descriptor adds version/hash fields, the importer needs a narrowly defined, explicit mapping from that exact archived descriptor to the new one, records both descriptors and original hashes, and verifies identical measured-clock input semantics. Unsupported/missing fields fail closed. Eligibility belongs to actual learner counters and audited collections; a descriptor conversion neither creates SAC updates nor promotes a source BC actor. `main_policy_compatible=false` remains appropriate.

Preserve the existing terminated-versus-truncated SAC backup behavior in this interface change. An explicit clock makes unseen times at a horizon cutoff an observable coverage concern; it does not justify resetting the bootstrap next-state clock or treating an unmeasured continuation tail as zero during calibration. Any change to finite-horizon learning semantics is a separate algorithm decision.

## Main-method and PCA boundary

The primitive is PCA of measured `(frames,16)` joint positions, not of the actor's observation vectors. A future eligible clock-SAC collection can therefore supply the same existing joint-only extraction with full source-interface provenance. No change is needed to PCA dimensionality, 90-percent variance selection, main MPC state, main 20-demonstration collection, main BC inputs or main actor architecture. Keep `cli.py:_train_locked` :324/:335 rejecting the clock kind and61D rotation actor; keep `pretrain` :272 creating the main60D rotation learner. A61D bootstrap policy must never be imported into the main learner by dropping a column.

Five force-qualified policy-only episodes must still come from one frozen checkpoint with actual positive SAC updates. Zero-update BC turns, mixed training-history exports, MPC-assisted recovery and five identical cold resets do not become SAC provenance or robustness evidence because a clock is present. The collector's physics auditor (`scripts/audit_policy.py:PhysicsObserver` :105, `audit_episode` :172) measures contacts/rotation independently of observation width; its force logic should remain unchanged.

## Required targeted tests before a later launch

1. **Adapter identity:** prescribed actions produce bit-identical physical states, rewards, flags and first60 observations with/without the adapter; only the actual-time feature is added. Reset zero, real terminal/truncated next time, measured float32 conversion and per-environment origins are checked. No time reset at a control handoff.
2. **Semantic rejection:** clock61/rotation is accepted only under its complete descriptor; raw60, goal61/reorientation, unknown61, incremental+clock, changed units/index/source and misleading metadata are rejected. Defaults remain byte-compatible at the observation level.
3. **Fresh import:** exact61D singleton mean/actions preserved on fixed actual source observations under the bound runtime; critics/targets/optimizers/alpha are fresh, std configured, true BC count retained and new SAC/critic/success counts zero. A descriptor migration records both identities without editing the source.
4. **Replay and optional preparation:** full61D episodes retain measured clock continuity, true reset boundaries, actual successor actions and invalid terminal successor actions; wrong clock or60D seed fails. MPC counts remain separate. Mid-episode supervised pairs cannot masquerade as full episodes.
5. **Resume:** interrupted/uninterrupted continuation matches clock, integration state, replay's pending successor, actions/RNGs and counters across an unfinished episode and a subsequent reset. Corrupted origin, time, dimension or adapter provenance rejects. Same-budget resume performs no action/reimport/std reset/pretraining.
6. **Collection and extraction:** a clock-aware fixture exercises five-episode assembly and primitive lineage while retaining all physical checks; timestamp/clock and goal-feature corruption fail. BC-zero-online and any failed episode still emit no eligible archive. Synthetic fixtures remain explicitly nonphysical evidence.
7. **Main separation:** the main rotation trainer/pretrainer stay60D, reject clock actors, and use only verified16-joint PCA data; copied BC/MPC sources cannot pass the frozen-SAC gate.
8. **Bounded real smoke if implementation is later selected:** zero new training updates, one imported actor, exact source-state input/action comparison and independent force audit with all clocks/physics retained. Import correctness is reported separately from task completion, stochastic exploration and post-success retention.

The review's snapshots, input hashes and reference map make this an implementation checklist, not an implemented interface or an experiment result. No noise floor, reward, support criterion, physics or stage requirement is relaxed.
