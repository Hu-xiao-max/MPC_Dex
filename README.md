# MPC-scaffolded dexterous reinforcement learning

Independent local implementation of [arXiv:2609.14878v1](https://arxiv.org/html/2609.14878v1), including the [companion primitive MPC method](https://arxiv.org/html/2609.14868v1). **The requested deployment is not complete:** the code and contact simulator are running, but a successful SAC-trained rotation policy and the full training/evaluation pipeline have not yet been verified. No physical robot has been controlled.

The authors' inspected public repositories contain websites and media, without deployable code, calibrated model assets or policies. This implementation uses a pinned public Allegro model and explicit reconstruction choices described in [reproduction.md](docs/reproduction.md). Published settings are recorded separately in [paper_reference.json](configs/paper_reference.json).

## Repository contents

The repository keeps the code (`mpc_dex/`, `scripts/`, `tests/`, `configs/`, `assets/`), the documentation (`docs/`, with [WORK_STATE.md](docs/WORK_STATE.md) as the running record of every experiment) and, for each of the 220 experiment directories under `artifacts/`, everything needed to read its result: `README.md`, `findings.md`, `protocol.json`, `config.json`, `summary.json`, `manifest.json`, the per-checkpoint in-run evaluation summaries (`evaluations/<checkpoint>/summary.json`), the stage scripts (`run.py`, `prepare.py`, `test_protocol.py`, probes), logs, the 30-trial frozen evaluations (`frozen_checkpoint_evaluation_0001/results*`), the verified demonstration collections (`mpc_cold_demonstrations_0001`, `cylinder_demonstrations_0001`), the labelled branches (`mpc_spine_tube_0001`, `mpc_dagger_labels_0001`) and the ten checkpoints named as reference results in this file and in `docs/WORK_STATE.md` (`checkpoints/<name>/agent.pt`).

The bulky run data was removed from the working tree in November 2026 and is not in the repository: per-episode training and evaluation transitions, replay buffers and environment snapshots of every checkpoint, the weights of checkpoints without a 30-trial evaluation, the 192 MB feedback-BC regressors, and the per-update `metrics.jsonl` logs (kept on the original machine as `metrics.jsonl.gz`). Each stage's `manifest.json` still lists the complete original file set with hashes, so a retained file can be checked against the run that produced it; the frozen source copies (`artifacts/*/source/`) and demonstration copies (`artifacts/*/sources/`) are reproduced by the code and collections tracked here.

## Run locally

```bash
uv sync --frozen
uv run --frozen python scripts/fetch_allegro.py
MUJOCO_GL=egl uv run --frozen python -m mpc_dex render --output artifacts/allegro_grasp.png
uv run --frozen python -m pytest -q
```

The 16-DoF hand holds a free 45 mm hexagonal object palm-down. A contact-based initial grasp is included and verified under normal gravity, without palm/table support. Its generation is reproducible with `uv run --frozen python scripts/find_grasp.py`. The scene and initial grasp are not the authors' calibrated hardware digital twin.

The independent components implement mean-only BC, frozen-actor Soft-SARSA,10-critic SAC, fixed 30/70 replay,40-step controller chunks with a 6000-step transition to policy, PCA primitives, constrained CEM and policy-only evaluation. Artifact contracts catch mismatched models, checkpoints and replay datasets. Unit and integration tests cover mathematical targets, episode boundaries, physical contact, planning constraints, scheduling and checkpoint reload.

The MPC evaluator copies the live simulator state into separate workers and checks actual contacts after every 2 ms transition. It stops rotation candidates on force-bearing palm support, table contact, workspace escape, divergence, or 50 ms without finger contact, including contact-loss time already elapsed in the live environment. Stable predictions match environment execution without modifying its state. An optional [exact native evaluator](docs/native_rollouts.md) accelerates the same physics and rejection checks; measured planning latency still exceeds the 10 Hz control interval.

Rotation success also requires that the entire episode avoid palm support. An exploratory MPC turn initially passed the earlier contact/tilt gate, but independent force audit found palm bracing; it is explicitly excluded from valid demonstrations. The corrected environment and trajectory validation now enforce the companion paper's no-palm condition. [WORK_STATE.md](docs/WORK_STATE.md) records experiments and remaining work.

## Training workflow

A successful simulation SAC policy must first generate genuine rotation trajectories for the MPC primitive. The first bootstrap run was invalidated for ballistic false successes; corrected twist measurement and grasp-retention regression checks now exclude them. An independently audited MPC diagnostic completes a full turn on the 40 mm object and retains it for another two seconds with no palm/table support. Its commands remain inside the paper's BC clipping range. The [recording](artifacts/mpc_matched40_bound098_0001/verified_bounded_turn.gif) establishes physical feasibility; it is not a learned SAC policy or a production primitive.

A later policy trained on consistent demonstration labels, followed by one numerical mean-head correction, now completes an independently verified turn at 0.9 seconds using policy control alone. Continued policy control drops the object at 1.2 seconds. This is a successful first-turn BC diagnostic, with unresolved sustained control and no SAC updates; [its artifacts](artifacts/bc_common_continuation_0001/) and [physics replay](artifacts/bc_common_policy_visual_0001/policy_turn_then_drop.gif) preserve both outcomes. Verified MPC recordings can seed bootstrap replay through `scripts/prepare_bootstrap_demonstrations.py`; actual physical replay, independent force auditing and episode-boundary checks are required. Demonstration counts stay separate from SAC success and exported policy trajectories. The bootstrap trainer supports checkpointed progress and resume:

```bash
uv run --frozen python scripts/train_bootstrap.py --help
```

Bootstrap can also import a compatible actor's mean into a fresh run while keeping critics, optimizers, temperature and new training counts separate. `--initial-actor` and source/runtime checks are described in [bootstrap initialization](docs/bootstrap_initialization.md). The successful BC diagnostic remains too sensitive to action noise for an established SAC initialization: all five prescribed samples fail at both the default bootstrap standard deviation and the existing minimum.

The completed [bootstrap0005 experiment](artifacts/bootstrap_0005/findings.md) imported that BC mean into fresh twin-critic SAC on the strict 40 mm task, with one nine-transition MPC seed and no additional BC or critic pretraining. It stopped at the prescribed 2,000 interactions and 1,745 SAC updates, with zero training or scheduled evaluation successes. The initial deterministic turn remains BC-origin; later evaluated policies failed. Scheduled checks repeated the same cold reset, so they do not estimate robustness. [Independent frozen value audits](artifacts/bootstrap_0005/value_calibration/findings.md) found all 15 stochastic samples failed and mean initial-action critic bias remained about +68 to +75 against complete terminal soft returns. Policies changed between checkpoints and bias did not grow monotonically; this does not establish a calibration improvement or an SAC implementation error. No trajectory from this run qualifies for a SAC primitive or advances the main stages.

Recent [corrective-control diagnostics](artifacts/mpc_common_noise_recovery_0001/findings.md) recover five prescribed noisy partial trajectories with MPC. A separate elapsed-time input improves BC fitting; its refined actor reaches 347.2° before dropping. MPC then [recovers one actual state visited by that actor](artifacts/mpc_clock_actor_recovery_0001/findings.md), supplying five more verified correction pairs. The resulting [86-pair BC extension](artifacts/bc_clock_actor_corrective_0001/findings.md) and its head refinement still fail under policy control; the latter peaks at 323.4° and drops. These 61-input clock experiments use a separate diagnostic interface and have no SAC updates. The main 60-input training stages remain pending. A [plot of the earlier policy and MPC recovery](artifacts/clock_recovery_comparison_0001/comparison.png) shows their shared prefix and different outcomes.

The [latest suffix probe](artifacts/bootstrap_suffix_support_0001/findings.md) finds stochastic support near the end of the turn: after eight physically replayed controls, all five fixed samples complete the remaining rotation with the unchanged initial SAC standard deviation .05. The same BC-origin actor fails all five samples from cold reset. This motivates a prefix curriculum, while preserving the distinction between assisted training outcomes and a successful policy operating from reset. No SAC learning occurred in that probe. A subsequent [fixed prefix-7 SAC trial](artifacts/bootstrap_suffix_sac_0001/findings.md) completed 500 critic-pretraining and 2,000 SAC updates. Its final frozen policy passes all five stochastic suffix trials and the deterministic trial; all six prefix-8 retention trials also pass. All six final cold-reset trials fail at control 1. This is learned assisted suffix control. The subsequent [gated prefix-6 warm-up](artifacts/bootstrap_suffix_sac_0002/findings.md) ran 256 frozen-policy episodes at the earlier handoff and found zero successes, all drops within five controls, so its success gate blocked further learning and the checkpoint is unchanged; prefix-7 retention still passes 6/6. A follow-up [MPC recovery from that handoff](artifacts/mpc_prefix6_handoff_recovery_0001/findings.md) completes a verified turn in five corrections, yielding five non-policy correction labels. A [mixed-demonstration SAC stage](artifacts/bootstrap_suffix_sac_0003/findings.md) then trained on those labels and the recorded continuation through the main-method 30/70 replay split; it produced no frozen success and lost prefix-7 retention (6/6 to 0/6), because the unchanged SoftSARSA entropy term inflates targets for demonstration actions the actor considers improbable. That checkpoint is not a valid initialization. A [corrective stage](artifacts/bootstrap_suffix_sac_0004/findings.md) with an entropy-free pretraining target removes the critic distortion but still yields no frozen success and again loses prefix-7 retention by online 500, so the remaining cause is the online actor updates on failure-dominated mixed data rather than the value targets. A [family of one-factor variants](artifacts/bootstrap_variant_template_0001/README.md) (74 stages, each hash-bound with per-checkpoint frozen evaluations and a separate [30-trial evaluation](artifacts/frozen_checkpoint_evaluation_0001/summary.md)) then found the remedy at the handoff: drop the MPC rows, supervise the actor toward the recorded handoff control with a tight spread anchor, and use a smaller actor step in chained stages. The resulting checkpoints complete the turn from the recorded prefix-6 handoff in 26–28 of 30 stochastic trials with prefixes 7–8 at 30/30, reach about half at prefix 4, and plateau near 20% at prefix 3, where the recorded trajectory's controls have success basins narrower than the policy can hit. Cold-reset MPC with the diagnostic prior produces verified demonstrations ([collection](artifacts/mpc_cold_demonstrations_0001/README.md), 37 stored); plain BC on them fails by multimodality ([demo_sac_0001](artifacts/demo_sac_0001/findings.md)), and a multi-source suffix curriculum over those demonstrations learns short suffixes across trajectories (85%, 59% and 28% for the last one, two and three controls at 30 trials) but slows for longer ones. That competence is per trajectory: the current multi-source checkpoints complete the last one or two controls of demonstrations they trained on and fail those they did not, beyond the final control; DAgger-style MPC labels at the states the policy visits on held-out demonstrations ([labels](artifacts/mpc_dagger_labels_0001/findings.md), [stage](artifacts/bootstrap_variant_0080_ms_dagger_from79/findings.md)) help less than simply adding those demonstrations as sources ([control](artifacts/bootstrap_variant_0081_ms_add_heldout_demos_from79/findings.md)), and neither transfers to an unseen trajectory. Handing off at the states that many demonstrations share near the cold reset (34 of 63 share their first control) with the policy completing the whole turn ([stage](artifacts/bootstrap_variant_0082_ms_shared_prefix_from81/findings.md), [ablation](artifacts/bootstrap_variant_0083_ms_shared_prefix_nosharedbc_from81/findings.md)) pins the shared first control but yields 0/30 from the cold reset and from every shared state: the continuations after the shared prefix are mutually incompatible with success basins far narrower than the policy's precision, and wrong-way rotation under failure teaches the critic to end episodes early. The cause is structural: the verified demonstrations are chaotic as open-loop sequences (a 0.0003 perturbation of the first control breaks the replay of seed_193 ten controls later; [probe](artifacts/frozen_checkpoint_evaluation_0001/spine_probe/README.md)), the MPC succeeds only by re-planning from the true state every control, and every policy this family has trained reproduces the open-loop tolerance of the last few controls rather than feedback. Coherent MPC corrections at perturbed states near one demonstration ([tube](artifacts/mpc_spine_tube_0001/findings.md), 166 verified branches from a reference-tracking planner) did not yield a feedback law in one 4,000-update stage ([stage](artifacts/bootstrap_variant_0087_ms_spine193_tube_from84/findings.md)), and the actor cannot even regress them in-sample. A deterministic labeller (1.0–1.5 s horizon, tracking penalty) and the best regressors then reached the data's interpolation floor (held-out error 0.013–0.020 against a per-step slack of 0.005–0.01), and a nearest-neighbour policy on those labels survives fresh perturbations only where the open-loop replay already does ([conclusion](artifacts/feedback_bc_0001/findings.md)): at this task interface the MPC's success is re-planning with lookahead, not a learnable local law. A longer control period ([control_period_0001](artifacts/control_period_0001/findings.md)) does not change this: the sensitivity is a sequence of discrete bifurcations at contact events of the hexagonal object (a perturbation contracts to zero between events and flips the outcome at one), so demonstrations at 0.2 and 0.3 s are as intolerant open-loop as at 0.1 s and 0.5 s fails the force audit; a circular object ([object_shape_0001](artifacts/object_shape_0001/findings.md)) shortens the intolerant prefix of a turn from five to nine controls to three. A cylinder campaign ([54 verified demonstrations](artifacts/cylinder_demonstrations_0001/README.md); stages `0089`–`0099` of the variant family, inheriting the hexagon multi-source checkpoint through a recorded geometry transfer) reproduced the same picture on that object: the frozen checkpoints complete the last one to three controls of training demonstrations (up to 120 of 150 trials at the last control, 60 of 90 on held-out ones), reach the last five to six controls only on the shortest 8-control demonstration (7–16 of 30), and never succeed from the cold reset or from the state one control after it (0 of 30 everywhere, 2 of 30 once). The reason is measured in [cylinder_first_control_0001](artifacts/cylinder_first_control_0001/findings.md): a behaviour-cloned actor reproducing that demonstration's eight controls to 1e-5 still fails from the cold reset, and perturbing the first control of a tested demonstration (eight cylinder, three hexagon) by 1e-6 to 1e-5 and replaying the rest fails in most directions for nine of the eleven and at 1e-4 for all, so the demonstrations are open-loop knife edges that no actor with a 0.02 residual can follow, whereas the re-planning MPC itself completes 7 of 12 strict turns with 0.035–0.10 of noise added to every executed control. What is missing is a corrective law, not precision, and that law cannot be imitated either: in the archived planner configuration its control at a state is set-valued ([cylinder_dart_0001](artifacts/cylinder_dart_0001/findings.md); fresh planners at one state disagree by 1 to 4, and noise-displaced copies of one closed loop return the hold or a rotation 1.9 away after one control and diverge into unrelated trajectories within two to three), so DAgger-style labels have no single-valued target. Long cold-reset reinforcement learning on the cylinder (40,000 interactions, ten times any earlier stage; [0100](artifacts/bootstrap_variant_0100_cyl_spine172_longrl_from99/findings.md) with the learned temperature, which diverged, and [0101](artifacts/bootstrap_variant_0101_cyl_spine172_longrl_alphafreeze_from99/findings.md) with it frozen, which learned stably) raised the frozen success from the state after two recorded controls to 17 of 30 but produced no success from the cold reset in 2,349 training episodes and 0 of 30 frozen trials, nor from the state after one control. No checkpoint succeeds from cold reset; the deployment prerequisite remains unmet. No assisted recording qualifies as a primitive. The [recorded outcome plot](artifacts/bootstrap_suffix_sac_plot_0001/outcomes.png) separates training recovery from frozen assisted and cold-reset results.

Bootstrap configurations can enable bounded joint-target increments and a separate retained-rotation shaping reward. Their angle observations expose retained progress. Checkpoint metadata identifies this interface, and `evaluate` restores it automatically; replay for this interface contains increment actions. Bootstrap0005 instead used absolute normalized joint targets and the original rotation reward, as do MPC demonstrations and the main BC/SAC stages. Successful measured joint-position trajectories provide the PCA input.

After a successful frozen SAC checkpoint exists, the [primitive collection guide](docs/primitive_collection.md) describes collecting five actual episodes with independent force audits and verified learner provenance. BC-only checkpoints are ineligible. The final bootstrap0005 checkpoint failed all five collection attempts, so it produced no eligible archive. `ROTATION_TRAJECTORIES.npz` below must be the qualified collection output. These commands are a workflow, not a claim that its stages have finished.

```bash
uv run --frozen python -m mpc_dex extract-primitive --trajectory ROTATION_TRAJECTORIES.npz --output artifacts/rotation_primitive.npz
uv run --frozen python -m mpc_dex collect --primitive artifacts/rotation_primitive.npz --output artifacts/mpc_demos
uv run --frozen python -m mpc_dex pretrain --replay artifacts/mpc_demos/replay.npz --output artifacts/pretrain
uv run --frozen python -m mpc_dex train --checkpoint artifacts/pretrain/checkpoint.pt --replay artifacts/mpc_demos/replay.npz --primitive artifacts/rotation_primitive.npz --output artifacts/online
uv run --frozen python -m mpc_dex evaluate --checkpoint artifacts/online/checkpoint.pt --output artifacts/policy_evaluation
```

Pretraining requires 20 verified successful MPC episodes and a matching dataset manifest. Default training uses 12,000 BC and 50,000 critic updates, then 12,000 online interaction steps with eight SAC updates each. Reduced counts do not satisfy the full-method gate. Output directories preserve input hashes and metrics; existing run directories are not silently overwritten.

Main online training saves atomic continuation checkpoints every 100 transitions and on SIGINT/SIGTERM after the current transition's updates finish. Resume the same output directory with the original configuration, primitive, fixed replay, seed and learner settings. `--steps` is the cumulative target; the original pretrained checkpoint path is inferred from the committed run:

```bash
uv run --frozen python -m mpc_dex train --resume artifacts/online --output artifacts/online --config configs/local_sim.json --primitive artifacts/rotation_primitive.npz --replay artifacts/mpc_demos/replay.npz --steps 12000
```

Resume restores the live simulator, unfinished episode, planner, scheduler, replay samplers and learner optimizers. Changed inputs or numerical sources are rejected; policy-only checkpoints cannot resume. See [checkpoint behavior and limitations](docs/online_resume.md).

Reorientation and alternative object geometries are represented in the simulator but need their own valid grasps, policy training and evaluation. Physical deployment additionally requires the actual hardware target, calibrated state/action mapping, robot transport and object tracking described in [deployment_requirements.md](docs/deployment_requirements.md).

## Reference and runtime evidence

`uv run --frozen python scripts/fetch_sources.py` refreshes source snapshots and checksums under `artifacts/sources/`. `scripts/check_runtime.py` checks dependency-level physics and rendering only. Experiment metrics and live process state, not those dependency checks, establish training progress. Menagerie model redistribution retains [its license](assets/allegro/LICENSE).
